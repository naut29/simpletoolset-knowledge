# AI Local Tools

## Overview

AI Local Tools focus on browser-side machine learning workflows where the model runs on your device instead of sending source files to an app server. Use them for summaries, OCR, voice transcription, and other private AI tasks with local-first processing.

This page is available in multiple languages on SimpleToolset (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID, HI, BN, TA, TE, MR).

## Key features

- Keep source text, audio, and images in the browser during AI workflows
- Use browser-side WebGPU or WASM inference where supported
- Reduce app-side upload requirements for sensitive material
- Reuse cached local model files for repeated runs in the same browser
- Combine privacy-first UX with practical AI assistance
- Run focused on-device AI tools without creating an account

## FAQs

- Are these AI tools fully local?: The processing workflow is local to your browser, but some tools may download model files from a model host on the first run before they can work on-device.
- Do my source files get uploaded to the app server?: These tools are designed to keep source material in the browser during processing. Review the privacy note on each tool for details about model downloads or caching.
- Do local AI tools work offline?: They can be more offline-friendly after assets and model files are cached, but actual offline behavior depends on browser storage support and whether required files are already available.
