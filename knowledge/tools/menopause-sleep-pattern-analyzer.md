# Menopause Sleep Pattern Analyzer - Private Local Sleep Journal

## Overview

Track night sweats, sleep quality, and possible triggers locally in a private menopause sleep journal.

Logs nightly sleep data, night sweats, possible triggers, and next-day impact in a private browser journal with local trend charts and offline-first storage.

This tool is available in multiple languages on SimpleToolset (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID, HI, BN, TA, TE, MR).

## Key features

- IndexedDB storage for private nightly records
- Offline-first route with scoped service worker support
- Local Chart.js dashboards for sleep and trigger patterns
- Tracks night sweats, awakenings, suspected apnea concerns, and notes
- JSON backup and restore without accounts

## How to use

1. Log the date, sleep hours, bedtime, and wake time
2. Rate sleep quality, night sweats, fatigue, and daytime impact
3. Tag possible triggers such as stress, alcohol, or a warm room
4. Review recent trends and common trigger frequencies
5. Export or import your private JSON backup when needed

## FAQs

- Does this diagnose sleep disorders?: No. It is a private tracking and reflection tool, not a diagnostic medical device.
- Where is my sleep data stored?: Entries are stored locally in your browser with IndexedDB and can be exported as your own JSON backup.
- Can it work offline?: Yes. It is designed as an offline-first route once the required assets have loaded in your browser.
- What if I suspect sleep apnea or severe daytime symptoms?: Those concerns should be evaluated by a qualified clinician rather than relying on a self-tracking tool.
