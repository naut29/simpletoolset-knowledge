# Lean Body Mass Calculator - Boer, James, Hume

## Overview

Compare lean body mass estimates with three popular formulas.

This tool estimates lean body mass (LBM) using Boer, James, and Hume formulas. It converts your height and weight to show results in kilograms and pounds.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

- Metric and imperial inputs

- Instant calculations

## How to use

1. Select metric or imperial units
2. Enter height and weight
3. Choose gender
4. Review LBM results from each formula

## FAQs
