# Base64 Encoder Decoder - Encode & Decode Text

## Overview

Encode and decode Base64 with optional URL-safe mode.

This tool converts text to Base64 or decodes Base64 back to readable text. It supports URL-safe Base64 variants for web use.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

## Key features

- Encode/decode toggle
- URL-safe Base64 option
- Unicode support
- Client-side only

## How to use

1. Paste text or Base64 data
2. Choose Encode or Decode
3. Toggle URL-safe mode if needed
4. Copy the output

## FAQs

- Is Base64 encryption?: No. Base64 is encoding, not encryption.
- What is URL-safe Base64?: It replaces + and / with - and _ and removes padding for URLs.
