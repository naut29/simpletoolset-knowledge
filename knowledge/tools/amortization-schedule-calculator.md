# Amortization Schedule Calculator - Payment Breakdown

## Overview

See exactly how each payment splits between principal and interest.

Build a period-by-period amortization schedule using loan amount, rate, and term.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

## Key features

- Period-by-period breakdown
- Balance tracking
- Supports custom payment frequencies
- Row limit for performance
- Instant output

## How to use

1. Enter loan amount, rate, and term
2. Choose payments per year
3. View the schedule table
4. Limit rows for quick viewing

## FAQs

- Why limit the number of rows?: Limiting rows keeps the table fast and readable for long terms.
- Is the last balance clamped to zero?: Yes, the schedule prevents negative balances.
