# Privacy-First OCR - Extract Text from Images Without Upload

## Overview

Extract text from receipts, screenshots, scans, and document photos locally in your browser.

Extract text from image files directly in your browser with local OCR. Upload a receipt, screenshot, scan, or document photo, choose the recognition language, and copy or download the extracted text without sending the image to a server.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

## Key features

- Client-side OCR for image files
- Language selection for English, Vietnamese, Chinese, Japanese, Korean, and Thai
- Canvas-based preprocessing for better readability
- Confidence score and word count
- Copy and TXT export
- No image upload to the app server

## How to use

1. Upload an image containing text
2. Choose the OCR language that matches the document
3. Optionally enable grayscale or high-contrast preprocessing
4. Run OCR and review the extracted text
5. Copy the result or download it as a TXT file

## FAQs

- Does this upload my image to your server?: No. OCR runs in your browser. The image stays on your device during recognition.
- Can it read receipts and ID cards?: Yes, as long as the image is clear enough. Receipts, scans, screenshots, and ID photos are common use cases.
- Why can the first run be slower?: The OCR engine may need to prepare worker files and language data the first time you use a language. After caching, later runs are faster.
- Does it support PDFs?: This tool is designed for images. For PDFs, render pages to images first or use a PDF text tool when the PDF already contains selectable text.
