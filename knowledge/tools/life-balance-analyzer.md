# Life Balance Analyzer - Balance Wheel Score

## Overview

See how your weekly time allocation balances key life areas.

This tool evaluates balance across six life areas using weekly time allocations. It outputs a balance score and an imbalance score to highlight gaps.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

## Key features

- Balance wheel breakdown
- Balance and imbalance scores
- Target-based deviation scoring
- Client-side calculation

## How to use

1. Enter weekly hours for each life area
2. Review the balance and imbalance scores
3. See category deviations from targets
4. Adjust inputs to test scenarios

## FAQs

- Are the targets fixed?: They are simple defaults used for comparison.
- Is this a diagnostic tool?: No. It is a self-assessment for reflection.
