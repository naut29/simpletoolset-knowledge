# Focus Ability Analyzer - Focus Stability Score

## Overview

Measure focus stability using session habits and distraction inputs.

This tool estimates focus stability from session length, break frequency, multitasking percentage, and notifications per hour. It outputs a 0-100 focus score.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

## Key features

- Focus stability score (0-100)
- Penalties for multitasking and notifications
- Session-length balancing
- Instant, client-side results

## How to use

1. Enter session length and break frequency
2. Add multitasking percentage and notifications
3. Review the focus stability score
4. Compare sessions across days

## FAQs

- What is multitasking percentage?: It is the share of time spent switching between tasks.
- Does it require tracking apps?: No. You can enter estimates.
