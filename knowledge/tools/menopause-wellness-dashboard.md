# Menopause Wellness Dashboard - Private Local Wellness Tracker

## Overview

Track menopause symptoms, sleep, mood, and energy together in a private local dashboard without backend health storage.

Creates a private browser dashboard for daily menopause wellness snapshots including sleep, mood, energy, stress, hot flash intensity, brain fog, symptom tags, and notes with local charts and on-device trend review.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

## Key features

- IndexedDB storage for private wellness records
- Offline-first route with a scoped service worker
- Local Chart.js dashboards for sleep, mood, energy, and symptom frequency
- Tracks daily wellness snapshots with symptom tags and notes
- JSON backup and restore without backend health profiles

## How to use

1. Log a daily snapshot with sleep hours, sleep quality, mood, energy, and stress
2. Rate symptom intensity such as hot flashes and brain fog for the day
3. Tag symptoms like night sweats, joint pain, mood swings, or vaginal dryness when relevant
4. Review private charts for trends in sleep, mood, energy, and symptom frequency
5. Export or import your JSON backup without using an account

## FAQs

- Is this dashboard stored on a backend?: No. The dashboard is built from data you enter yourself and stores records locally in your browser with IndexedDB.
- Does it work offline?: Yes. It is designed as an offline-first route once the required assets have loaded in your browser.
- Can it replace medical advice?: No. It only helps track personal trends and does not replace professional advice.
- What does it track in one place?: It combines sleep, mood, energy, stress, symptom intensity, symptom tags, and notes in one local menopause dashboard.
- Do I need an account to use it?: No. It is designed to work without accounts, cloud sync, or backend health profile storage.
