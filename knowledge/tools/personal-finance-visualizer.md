# Personal Finance Visualizer - Private CSV Expense & Cash Flow Tracker

## Overview

Analyze bank statements locally from CSV files with a private browser-based finance tracker.

Load a CSV bank statement locally, map columns such as date, description, income, expense, or amount, and generate private cash-flow summaries and category charts in your browser.

This tool is available in multiple languages on SimpleToolset (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID, HI, BN, TA, TE, MR).

## Key features

- Private finance tracker that runs in your browser
- CSV and TSV statement parsing with manual column mapping
- Monthly cash-flow chart and expense-by-category chart
- Local snapshot saving with browser storage
- No account, no upload, and no server-side storage

## How to use

1. Open a local bank statement CSV or TSV file
2. Map the detected columns to date, description, amount, income, expense, and category
3. Run the local analysis to build summaries and charts
4. Review monthly cash flow, category spending, and recent transactions
5. Save a local snapshot in browser storage if you want to reopen the latest result

## FAQs

- Does this upload my bank statement?: No. The CSV statement is parsed and analyzed locally in your browser.
- Can I use this with exported bank CSV files?: Yes. The tool is designed for bank statement CSV or TSV exports and lets you map columns when headers differ.
- Is this a budgeting app with accounts?: No. It is a private browser-side visualizer for local statement analysis and quick expense review.
