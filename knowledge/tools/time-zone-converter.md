# Time Zone Converter - Convert Between Global Time Zones

## Overview

Convert times between global time zones with DST-aware, client-side calculations.

Convert date and time between global time zones using IANA time zone data and the Intl API. Handles daylight saving time changes automatically.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

## Key features

- IANA time zone support
- DST-aware conversions
- Source and target offsets
- Swap and reset controls
- Client-side processing
- Curated common zones list

## How to use

1. Enter a date and time
2. Select a source time zone
3. Select a target time zone
4. Swap zones if needed
5. Copy the converted time

## FAQs

- Does it handle daylight saving time?: Yes. The converter uses Intl.DateTimeFormat with IANA time zones, which applies DST rules automatically.
- Is this tool offline?: All calculations run in your browser, with no external API calls.
