# IPv4 Subnet Calculator - Network & Broadcast Details

## Overview

Calculate subnet details from IPv4 and CIDR.

This tool calculates network details from an IPv4 address and CIDR: network address, broadcast, usable range, netmask, and total hosts.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

## Key features

- Network and broadcast calculation
- Usable range output
- Netmask conversion
- Client-side only

## How to use

1. Enter an IPv4 address
2. Enter a CIDR prefix
3. Review network and broadcast addresses
4. Copy results if needed

## FAQs

- How are /31 and /32 handled?: The tool shows network and broadcast addresses with appropriate usable ranges.
- Does it support IPv6?: No. This calculator is IPv4 only.
