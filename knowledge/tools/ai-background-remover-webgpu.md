## FAQs

- Does this upload my image to the app server?: No. The image stays in the browser during background removal. Model files may download from the model host on the first run, but the source image itself is not uploaded to the app server.
- What file does it export?: It exports a transparent PNG cutout so you can place the subject over another background or use it in design workflows.
- Will it remove every background perfectly?: No. It works best on clear subjects with visible edges and should still be reviewed before you publish or ship the final asset.
- Does it support offline use?: The route is built with offline support, and browser cache can help after the first model download. Exact offline behavior still depends on whether the model files and app assets are already cached.
