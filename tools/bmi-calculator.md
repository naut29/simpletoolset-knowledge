# BMI Calculator - Body Mass Index & Category

## Overview

Use BMI to get a fast, consistent snapshot of body mass index from height and weight.

This BMI calculator computes body mass index from your height and weight and returns the BMI value plus a category (underweight, normal, overweight, obese). You can switch between metric and imperial units for quick comparisons.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

## Key features

- Metric and imperial unit support
- Instant BMI value and category
- Clear category thresholds
- Privacy-first client-side calculation

## How to use

1. Choose metric or imperial units
2. Enter your height and weight
3. View your BMI value
4. Check the category result
5. Copy results if needed

## FAQs

- Is BMI a medical diagnosis?: No. BMI is a screening metric based on height and weight and does not diagnose health conditions.
- Which units can I use?: You can use metric (cm/kg) or imperial (in/lb) units and the calculator converts them automatically.
