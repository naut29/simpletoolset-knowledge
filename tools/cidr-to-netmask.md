# CIDR to Netmask Converter - IPv4 CIDR Table

## Overview

Convert CIDR to netmask with a handy /0-/32 table.

This tool converts CIDR notation to IPv4 netmask and reverses netmask to CIDR. It also provides a quick reference table.

This tool is available in multiple languages on SimpleToolset (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID, HI, BN, TA, TE, MR).

## Key features

- CIDR to netmask conversion
- Netmask to CIDR conversion
- Reference table /0-/32
- Client-side only

## How to use

1. Enter a CIDR value
2. Enter a netmask value
3. Review the converted results
4. Use the reference table for quick checks
