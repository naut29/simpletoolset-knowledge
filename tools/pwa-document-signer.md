# PWA Document Signer - Sign PDF in Your Browser Without Uploading

## Overview

Apply a visible signature to a PDF locally in your browser and keep SHA-256 fingerprints before and after signing.

Add a visible signature to a PDF in your browser by drawing, typing, or uploading a signature image, then export the signed file with SHA-256 fingerprints for before-and-after integrity tracking.

This tool is available in multiple languages on SimpleToolset (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID, HI, BN, TA, TE, MR).

## Key features

- Draw, type, or upload a visible signature
- Sign the first page, last page, all pages, or a custom page
- Choose signature placement and scale
- Generate SHA-256 fingerprints in the browser
- No server upload for the PDF or signature asset

## How to use

1. Upload the PDF you want to sign
2. Choose a drawn, typed, or image-based signature
3. Select the target page and placement
4. Download the signed PDF and note the SHA-256 fingerprints

## FAQs

- Does this create a certificate-backed digital signature?: No. This tool places a visible signature on the PDF and generates SHA-256 fingerprints, but it does not create a PKI-backed PDF digital signature.
- Is the PDF uploaded anywhere?: No. The PDF stays in your browser while the signature is applied and the output file is generated.
- Can I use my handwritten signature image?: Yes. You can draw a signature, type one, or upload a signature image.
