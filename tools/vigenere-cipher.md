# Vigenere Cipher - Encrypt and Decrypt Text

## Overview

Encrypt and decrypt text with the classic Vigenere cipher for education and puzzles.

Encrypt and decrypt text using the Vigenere cipher with a keyword. This is a classical cipher used for education, puzzles, and non-secure encoding.

This tool is available in multiple languages on SimpleToolset (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID, HI, BN, TA, TE, MR).

## Key features

- Encrypt and decrypt modes
- Keyword-based cipher
- Supports letters and basic text
- Instant output
- Client-side processing
- Copy-friendly results

## How to use

1. Choose encrypt or decrypt
2. Enter your text
3. Enter a keyword
4. Generate the output
5. Copy the result

## FAQs

- Is Vigenere secure?: No. It is a classical cipher and should not be used for real security.
- What characters are supported?: It is designed for letters; other characters may be passed through unchanged.
- Do I need the same keyword to decrypt?: Yes. The keyword must match exactly.
- Is my text stored?: No. Processing happens locally in your browser.
