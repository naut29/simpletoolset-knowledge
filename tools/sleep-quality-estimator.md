# Sleep Quality Estimator - Sleep Score & Debt

## Overview

Estimate sleep quality and sleep debt with simple nightly inputs.

This tool estimates sleep quality using bedtime, wake time, duration, awakenings, and pre-sleep screen time. It also reports estimated sleep debt.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

## Key features

- Sleep score on a 0-100 scale
- Sleep debt estimate in hours
- Routine-based scoring rules
- Private, client-side computation

## How to use

1. Enter bedtime and wake time
2. Add duration, awakenings, and screen time
3. View sleep score and sleep debt
4. Adjust inputs to compare routines

## FAQs

- Is this a sleep study?: No. It is a lightweight estimator based on inputs.
- What is sleep debt?: Sleep debt is the gap between ideal sleep and your actual sleep duration.
