## FAQs

- Does the broken code get uploaded to the app server?: No. The code stays in the browser while the local repair workflow runs. Model assets may download from the model host on the first run, but the snippet itself is not uploaded to the app server.
- What kinds of code snippets is it meant for?: It is meant for small HTML, CSS, JavaScript, and JSON snippets that need quick structural repair, not full production codebases.
- Can it guarantee the code is correct?: No. It produces a private local draft and some quick checks, but you should still test the repaired code in the real environment.
- Is JSON repair different from general code repair?: Yes. The tool also uses deterministic local cleanup for common JSON problems such as trailing commas, comments, or unquoted keys.
