# Private Voice-to-Text (Whisper Web) - Free Online Tool

## Overview

Transcribe local audio files and meeting recordings with a private Whisper workflow in your browser without uploading the media to the app server.

Transcribe local audio or video recordings into text with a Whisper model running in your browser, with selectable language hints, browser-side inference backends, and timestamped transcript chunks.

This tool is available in multiple languages on SimpleToolset (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID, HI, BN, TA, TE, MR).

## Key features

- Local Whisper transcription in the browser
- Audio and meeting recording transcription without app-side uploads
- Language hint selection for supported site languages
- Timestamped transcript chunk preview
- Browser cache reuse after initial model download

## How to use

1. Upload an audio or video recording from your device
2. Choose auto-detect or set a source language hint
3. Pick auto, WebGPU-preferred, or WASM-only backend mode
4. Run local transcription and copy or download the transcript

## FAQs

- Does the recording get uploaded to the app server?: No. The recording stays in your browser during transcription. Model files may download from the model host on the first run, but your media is not uploaded to the app server.
- Can I transcribe meeting recordings?: Yes. This tool is suitable for local-first meeting notes, voice memos, interviews, and other speech-heavy recordings that your browser can decode.
- Does it support timestamps?: Yes. The tool previews transcript chunks with timestamps so you can review the structure of the recording.
- Can it work after the first model download?: In many cases, yes. Browser cache can reuse model files for later local runs, but exact behavior depends on browser storage support.
