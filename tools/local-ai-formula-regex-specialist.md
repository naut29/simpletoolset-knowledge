# Local AI Formula & Regex Specialist - Private Excel, SQL, and Regex Generator

## Overview

Generate Excel formulas, SQL queries, and regex patterns locally in your browser from natural-language descriptions with a private code-model workflow.

Turns natural-language requests into draft Excel formulas, SQL queries, and regex patterns inside the browser with a local code-model workflow, so prompts and generated logic do not need to leave the device for app-server processing.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

## Key features

- Private prompt handling in the browser
- Three generation modes: Excel, SQL, and regex
- Target dialect selection for spreadsheets, databases, and regex engines
- WebGPU or WASM backend choice for local inference
- Structured output with assumptions, examples, and review notes

## How to use

1. Choose whether you need an Excel formula, SQL query, or regex pattern
2. Describe the logic you want in plain language
3. Add optional context such as table names, sample text, or cell ranges
4. Let the browser load the local code model and generate a draft result
5. Review the output, assumptions, and warnings before reusing the logic elsewhere

## FAQs

- Does my prompt get uploaded to your app server?: No. The request stays in the browser while the local model runs. The first run may still need to download model assets from the model host.
- Are the generated formulas and queries guaranteed to be correct?: No. The result is a local draft that can save time, but you should still validate references, joins, escaping, and edge cases before production use.
- Can it target different SQL or regex dialects?: Yes. You can steer generation toward common spreadsheet targets, several SQL dialects, and multiple regex engines.
- Is this useful without extra context?: Yes, but outputs improve when you include relevant schema, sample text, or range details.
