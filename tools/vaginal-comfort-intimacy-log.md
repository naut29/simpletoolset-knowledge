# Vaginal Comfort & Intimacy Log - Private Local Comfort Tracker

## Overview

Track vaginal dryness, irritation, and intimacy comfort locally in a private browser journal without cloud sync.

Logs vaginal dryness, irritation, intimacy comfort, pain, libido, symptom context, and notes in a private browser journal with local charts and on-device pattern review.

This tool is available in multiple languages on SimpleToolset (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID, HI, BN, TA, TE, MR).

## Key features

- IndexedDB storage for private symptom records
- Offline-first route with a scoped service worker
- Local Chart.js charts for dryness, irritation, and comfort trends
- Tracks notes, context tags, lubricant use, moisturizer use, and symptom flags
- JSON backup and restore without accounts or cloud sync

## How to use

1. Log the date and rate dryness, irritation, comfort, pain, and libido
2. Mark context such as stress, poor sleep, dehydration, intimacy, or new products
3. Note whether itching, unusual discharge, bleeding, odor, lubricant use, or moisturizer use were present
4. Review local charts for trend changes and repeated pattern counts
5. Export or import your private JSON backup when needed

## FAQs

- Does this diagnose infection or a gynecologic condition?: No. It is a private tracking tool for personal pattern review and does not diagnose infection or gynecologic disease.
- Where is the journal stored?: Entries are stored locally in your browser with IndexedDB and can be exported as your own JSON backup.
- Can it work offline?: Yes. It is designed as an offline-first route once the required assets have loaded in your browser.
- Is any sensitive data uploaded?: No. The journal is designed for local browser storage only, with no account, no server sync, and no sharing built into the workflow.
- When should I seek medical care instead of only logging symptoms?: Pain, bleeding, unusual discharge, unusual odor, persistent burning or itching, or pain during sex should be evaluated by a clinician.
