# Perimenopause Bleeding Log - Private Local Bleeding Tracker

## Overview

Track irregular periods and bleeding changes in a private local journal with offline export and no cloud sync.

Tracks irregular periods, spotting, bleeding intensity, pelvic pain, fatigue, clot-related notes, and warning-pattern tags in a private browser journal with local charts and offline export tools.

This tool is available in multiple languages on SimpleToolSet (EN, VI, ZH, KO, JA, TH, DE, PT-BR, ES-419, ID).

## Key features

- IndexedDB storage for private bleeding records
- Offline-first route with a scoped service worker
- Local Chart.js views for bleeding, pain, fatigue, and tag frequency
- Tracks warning-pattern tags alongside routine entries
- JSON backup plus CSV export without cloud sync

## How to use

1. Log the date and record the flow type and bleeding level
2. Rate pelvic pain and fatigue for the same day
3. Tag context such as unexpected timing, spotting, large clots, dizziness, or bleeding after sex
4. Review local charts to see repeated bleeding or warning-pattern trends
5. Export JSON or CSV locally when you want a private copy for your own records or a doctor visit

## FAQs

- Does this tool tell me why abnormal bleeding is happening?: No. It only helps organize personal bleeding patterns and does not determine the medical cause.
- Where is my data stored?: Entries are stored locally in your browser with IndexedDB unless you export your own file.
- Can I export something for a doctor visit?: Yes. You can export your entries locally as JSON or CSV without uploading them anywhere.
- Does it work offline?: Yes. It is designed as an offline-first route after the required assets have loaded.
- When should I seek medical care instead of only logging entries?: Postmenopausal bleeding, very heavy bleeding, prolonged bleeding, large clots, dizziness, or bleeding after sex should be evaluated promptly.
